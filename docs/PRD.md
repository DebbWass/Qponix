## 1. Overview

### 1.1 Product Vision
Qponix היא אפליקציית Android לניהול קופונים וגיפטקארדים וירטואליים המתקבלים בהודעות SMS.  
המוצר מרכז את כל הקופונים במקום אחד, מאפשר מעקב אחרי יתרות, וחוסך זמן חיפוש בין הודעות.

### 1.2 Problem Statement
משתמשים המקבלים קופונים/גיפטקארדים ב-SMS מתמודדים עם:
- חיפוש ידני בין עשרות הודעות SMS
- אי ידיעת אילו קופונים נוצלו ואילו לא
- חוסר מעקב על יתרה חלקית שנשארה
- איבוד קופונים שפג תוקפם ללא התראה
- מעבר מסורבל בין פרטי קופונים שונים

### 1.3 Target Users
משתמשים פרטיים המקבלים גיפטקארדים/קופונים דיגיטליים (מתנות, מבצעים, תגמולים).

## 2. Functional Requirements

### FR-01: קריאה אוטומטית של SMS
- האפליקציה תקרא הודעות SMS קיימות בעת ההתקנה הראשונה (inbox scan)
- האפליקציה תקבל הודעות SMS חדשות בזמן אמת (BroadcastReceiver)
- מנגנון חכם (parser) יזהה הודעות קופון לפי pattern-matching ו-confidence scoring
- הסכום, קוד הקופון, וכתובת האתר יחולצו אוטומטית

### FR-02: מסך ראשי — רשימת קופונים
- 5 טאבים: **פעיל / עומדים לפוג / פגי תוקף / ארכיון / נמחקו**
- כרטיסיית קופון: שם שולח, קוד, סכום, יתרה, תאריכים, אינדיקטור סטטוס
- מיון: לפי תאריך, סכום, שם בית עסק
- חיפוש/סינון בזמן אמת
- מצב בחירה מרובה (long-press) לפעולות ב-batch

### FR-03: מסך פרטי קופון + ניווט Swipe
- לחיצה על קופון פותחת מסך פרטים
- **החלקה ימינה/שמאלה מעבירה לקופון הבא/קודם ברשימה הנוכחית** ← *חדש ב-v1.2*
- כותרת המסך מציגה מיקום נוכחי: "קופון 2 מתוך 5 • החלק לניווט"
- שדה לעדכון יתרה חלקית שנשארה
- היסטוריית שימושים (תאריך + סכום שנוצל)
- עריכת תאריך תפוגה
- הוספת הערות

### FR-04: מחיקת קופון ממומש
- כפתור "מימשתי" יסמן קופון כ-used ויעביר לארכיון
- מחיקה רכה — קופונים שנמחקו עוברים לטאב "נמחקו" עם אפשרות שחזור

### FR-05: ניהול ידני
- הוספת קופון ידנית (ללא SMS)
- עריכת פרטי קופון שחולץ בצורה שגויה

### FR-06: העתקה מהירה
- לחיצה ארוכה / כפתור על קוד הקופון → העתקה ל-clipboard + toast

### FR-07: התראות תפוגה
- התראה X ימים לפני תפוגה (configurable בהגדרות, ברירת מחדל: 3 ימים)
- הגדרת מילות מפתח מותאמות לזיהוי קופונים ב-SMS

### FR-08: ניווט Swipe בין קופונים ← *חדש ב-v1.2*
- במסך פרטי קופון — החלקה ימינה/שמאלה מעברת לקופון הסמוך ברשימה הנוכחית
- העמוד הסמוך נטען מראש (preload) לחוויה חלקה
- אינדיקטור "X מתוך Y" בכותרת
- כל קופון שומר מצב עצמאי (dialog פתוח, עדכון יתרה בתהליך, וכדומה)

## 3. Non-Functional Requirements

| קטגוריה | דרישה |
|----------|-------|
| ביצועים | טעינת רשימה עד 200 קופונים ב-<500ms |
| ניווט | מעבר Swipe בין קופונים <100ms |
| אבטחה | כל הנתונים מאוחסנים locally בלבד, ללא שרת |
| פרטיות | אין שיתוף נתונים עם צד שלישי |
| Offline | כל הפונקציונליות עובדת ללא חיבור לאינטרנט |
| UX | Material Design 3, תמיכה ב-RTL (עברית) |
| API Level | Android 8.0+ (API 26) |
| גודל | עד 20MB APK |

## 4. Permissions Required

| הרשאה | סיבה |
|-------|------|
| `READ_SMS` | קריאת הודעות SMS קיימות |
| `RECEIVE_SMS` | קבלת SMS חדשים בזמן אמת |
| `POST_NOTIFICATIONS` | התראות לפני תפוגת קופון |
| `INTERNET` | פתיחת קישורי אתרים מהקופון (Chrome/browser) |
| `VIBRATE` | ויברציה בהתראות |

> **הערה:** החל מ-Android 10, גישה ל-SMS מוגבלת. הגשה ל-Google Play דורשת הצהרת שימוש ייעודי.

## 5. Out of Scope (v1.x)

- תמיכה ב-iOS
- סנכרון ענן / backup לשרת
- OCR מתמונות
- שיתוף קופון עם משתמשים אחרים
- פרסום ממומן / monetization

---

## 6. Success Metrics

- זיהוי נכון של קופון מ-SMS: >85% דיוק
- זמן מהתקנה לצפייה בקופון ראשון: <2 דקות
- מציאת קופון ספציפי: <5 שניות
- מעבר בין קופונים ב-swipe: <100ms
